- **Gmail Import**: Uses `hooks/use-gmail-import.tsx`, `lib/import/store.ts`, `lib/import/parsers/`, OAuth via `lib/import/oauth.ts`.

- **Image**: Use `next/image` with remote patterns in config. Lazy loading default.
